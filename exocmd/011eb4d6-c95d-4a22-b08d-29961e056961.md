# Is prototype

Reusable **AtomicPrecondition** — returns `true` when the target's `exo__Instance_class` chain reaches `exo__Prototype` via a native transitive `exo:Class_superClass*` walk (i.e. the target IS a prototype). The walk resolves at query time through the class-hierarchy resolver (req `9fddda62`, `ClassHierarchyResolvingStore`), which bridges the symbolic↔file-IRI seam so the super-class path fires for symbolic-form instances. De-hacked (req `5579ffa1`) from the earlier `STRENDS(STR(?c), "Prototype")` suffix workaround, which was needed only while the pure-SPARQL walk could not resolve (CLAUSE FINDING); the semantic walk catches every prototype class by its class chain — independent of the `…Prototype` naming convention. Originally extracted from the duplicated inline guard copied across ~20 preconditions (RFC df602adc Phase 6).

Wrapped by a NotPrecondition (`5b49ef19-7eb9-4b67-bb4e-c9002537000b`, "Not a prototype") to get the negation — the "not-prototype" guard used by the criticality-zone commands. Composing this single leaf into multiple composites makes reuse / CQ3 non-vacuous.
