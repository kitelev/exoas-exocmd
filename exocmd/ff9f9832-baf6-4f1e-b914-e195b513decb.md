# Cold Archive

Relocates an asset into the **dated cold-archive namespace** (`$my-archive-YYYY-MM`
in `exoas-my-archive`, excluded from every profile → physically off-device). Cold
counterpart of «Archive Ontologically»: same emergent composition of shipped
grounding primitives (property_set + service_call repairFolder), zero engine code.

Composite [[4fba7a3a-e14c-418d-9b13-a3920f6fbce1|Cold Archive (composite)]]:
1. Re-anchor isDefinedBy ← latest cold-archive ontology (NamedQuery, ORDER BY DESC url).
2. repairFolder → moves the file into that namespace folder (cross-assetspace co-location).

⚠ Resolves ONLY where `exoas-my-archive` is mounted (the Mac working vault vault-my-full);
elsewhere the NamedQuery is empty → safe no-op. CLI: `apply cold-archive <asset>`.
