# Rollback Done to Backlog (composite)

Composite grounding for the Rollback Done to Backlog command (two-step backward transition):

1. `workflow_transition rollback` (`7eb97e7d`) — resolves at runtime `Done → Doing` (Re-open), clears end/resolution timestamps
2. `workflow_transition rollback` step (`b98e24c0`) — resolves at runtime `Doing → Backlog` (Rollback to Backlog), clears start timestamp

Atomic via `GroundingExecutor.executeComposite` rollback on step failure. Used by command `Rollback Done to Backlog` (`27b2ea61`).

Note: steps must be distinct grounding assets — two identical dispatcher refs do not execute twice.
