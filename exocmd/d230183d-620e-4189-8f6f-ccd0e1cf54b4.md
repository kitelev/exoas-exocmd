Sets ems__Effort_status to Done ([[7b9b3116-7c3c-438c-9618-94fe301320a6]]) AND stamps user-supplied fact timestamps ems__Effort_startTimestamp and ems__Effort_endTimestamp, in ONE intent command. For logging work that actually finished earlier ('задним числом') where the real start/end are known.

- **Grounding**: 0923384a 'Mark Done Post Factum With Time (composite)' — 3 steps: status-Done (reused bdf3c81f) + start/end via service_call updateProperty reading $input.start / $input.end.
- **Input**: --input '{"start":"2026-10-22T11:32:00","end":"2026-10-22T12:10:00"}'.
- **Precondition**: b28caa2b (same as mark-done-post-factum — not-a-prototype AND visible-until-Done).
- **Icon**: history. **Category**: status. **CLI**: apply mark-done-post-factum-with-time <path> --input '{"start":...,"end":...}'.

Contrast: mark-done-post-factum (8abd723a) = status only (no timestamps); this = status + both fact timestamps.
