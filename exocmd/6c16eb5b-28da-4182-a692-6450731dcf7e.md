# exocmd__CreationGate_guardedClass

Охраняемый класс правила допуска (1..N). Кандидат касается правила, если хоть один его класс входит в замыкание `guardedClass` по `exo__Class_superClass` и не входит в замыкание `excludedClass`.

Значение — класс в любой форме ссылки (UID, UID с меткой, метка). Без распознанного значения область правила неизвестна ⇒ правило отказывает любому созданию в vault, кроме создания нового ассета правила.
