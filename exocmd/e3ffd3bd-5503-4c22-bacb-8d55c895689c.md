Ставит `idea__Idea_status` = «В работе» — исход «в работу» утреннего пересмотра идей (решение фаундера 22.11 №1: статус плюс задача первого шага; задачу создаёт исполнитель пересмотра, не команда).

Пара к `idea-park` / `idea-trash`: те же привязки, то же разведение по свойству статуса — идея с `ems__Effort_status` получает «в работу» командой `start-effort` (привязка к `ems__Idea`).

- **Потребитель**: исполнитель пересмотра `~/.claude/bin/ideas-review-apply.py` выбирает команду по свойству статуса идеи.

Источник: RFC `ea34c663-8789-44e4-a1fe-200057cc49a7` (решение фаундера 22.11 №1), задача Ф1 `24ff9cf5-cd98-4a61-aa84-37c0b00361b2`.
