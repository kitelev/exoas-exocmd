# Not a prototype and visible until Done

**AllPrecondition** (AND) of two shipped atomics:

1. [[847c37e0-9812-4dc7-9a92-923dac7cda56|Target is not a prototype]] — the shared prototype guard every instance-lifecycle command carries.
2. [[37517554-8308-4b38-9841-a9b1619ae092|Visible until Done (atomic action)]] — hides the command once the effort is Done.

## Why it exists

«Mark Done Post Factum» (`8abd723a-ab16-4c66-875a-997e1d4ad038`) pointed at atomic `37517554` **alone**, so it was offered on prototype targets — where "mark this done, retroactively" is meaningless, since a prototype is a template and never runs.

The regression guard `PrototypePreconditionForgetGuard` in `kitelev/exocortex` requires every instance-lifecycle command to enforce the not-a-prototype clause, flat or nested. It went red the moment the `packages/exoas-exocmd` submodule pointer was bumped past this drift; the stale pointer had been masking it.

⚠ The command deliberately keeps its **not-Done** gate rather than the newer «Visible until terminal» (`067e481d`): «Mark Done Post Factum» is exactly the escape hatch for a mistakenly-trashed task, so it must stay visible on Trashed. That is why the existing composite `c57642c4` («Visible until terminal, not a prototype, not archived») is **not** reused here — its semantics are different on both the Trashed and the archived axis.

`37517554` itself is left untouched (req 127763f8 explicitly kept it for this one consumer).
