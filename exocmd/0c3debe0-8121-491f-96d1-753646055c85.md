# Trash

Asks for a reason, records it as its own `ems__EffortTrashNote` asset linked to the target (`exo__Asset_relates`), then sets `ems__Effort_status` to Trashed, stamps `ems__Effort_trashedReason` («Неактуально / осознанный отказ» — deliberate-drop default) AND `ems__Effort_resolutionTimestamp` with the current local timestamp. The target's body is never rewritten (req `088f94c6`).

- **Input**: `label` — the reason, required. CLI: `apply trash <path> --input '{"label":"…"}'`; without it (or blank) the command refuses and changes nothing.
- **Precondition**: Visible only when asset is NOT already Trashed
- **Grounding**: Composite (`d612e5f5`) — creates the reason asset first, then sets status + category + resolutionTimestamp atomically
- **Icon**: x-circle (Lucide)
- **Category**: status

Note: 2026-06-28 `Cancelled` status collapsed into `trashedReason`. Single «not-Done» terminal = Trashed; reason captures *why*. For an abandoned (started-not-finished) task, set `trashedReason` accordingly — the command's default reason assumes deliberate drop.
