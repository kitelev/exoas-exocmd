# exocmd__CreationGate_exemptEvidence

Регэксп улики отгруженного (строка, не более одного значения). Применяется без учёта регистра к тексту кандидата. Значение исполняют JavaScript и Python ⇒ запись переносимая: без `\b` рядом с кириллицей и без `\w`.

Регэксп не компилируется ⇒ путь улики закрыт, кандидат судится цепочкой, причина в отказе называет регэксп.
