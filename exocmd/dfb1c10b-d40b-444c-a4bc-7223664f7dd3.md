# Park — Waiting → ems__Idea binding

Привязка «Park — Waiting» (`park-waiting`) к `ems__Idea`. Идея с `ems__Effort_status` (личные идеи vault-my) — кнопки недельного дайджеста PO. Идеи без `ems__Effort_status` ведут `idea-trash` / `idea-park` (пишут `idea__Idea_status`).
