# Resolve latest cold-archive ontology

NamedQuery for the «Cold Archive» command. Resolves the LATEST dated cold-archive
namespace (`$my-archive-YYYY-MM` in `exoas-my-archive`) by ordering all
`my-archive-*` ontologies by URL descending. Consumed read-side by the
`property_set` grounding's `targetValueQuery` (CQRS bridge). Global (no
`$currentAsset` hop) — every cold-archived asset goes to the current month's
namespace. Resolves ONLY where `exoas-my-archive` is mounted (vault-my-full);
elsewhere returns empty → command is a safe no-op.

```sparql
SELECT ?archiveOnto WHERE { ?archiveOnto <https://exocortex.my/ontology/exo#Ontology_url> ?url . FILTER(STRSTARTS(STR(?url), "https://exocortex.my/ontology/my-archive-")) } ORDER BY DESC(?url) LIMIT 1
```
