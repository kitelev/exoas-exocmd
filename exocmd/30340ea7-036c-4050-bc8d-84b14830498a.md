# exocmd__CreationGate_excludedClass

Безусловно исключённый класс (0..N): классы кандидата из замыкания `excludedClass` не охраняются. Исключение судится по каждому классу кандидата: `[ems__Task, ems__TaskPrototype]` охраняется, потому что `ems__Task` не исключён.

Источник: onto-RFC `4a8d887a` (Approved 08.10.2026), тикет `316dd2be`.
