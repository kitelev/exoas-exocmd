# Create Narrower Concept

Кнопка видна на любом инстансе `concept__Concept`: клик → форма (название +
необязательное определение) → создаётся дочерний концепт.

## Что именно происходит (2026-09-27, #4358)

Команда исполняется **гомоиконичным** основанием `[[85c40d1e-02b7-43c6-832b-d0b481ed19fb]]`
типа `create_instance` — TypeScript-сервиса в пути больше нет:

| что | чем задано |
|---|---|
| класс нового ассета | `exocmd__Grounding_targetClass` → `concept__Concept` |
| папка | `$isDefinedByFolder` — **рядом с родителем**, по его онтологии |
| анкер (`exo__Asset_isDefinedBy`) | наследуется от родителя правилом `[[cbe000c4-b29a-4405-876d-790fb2296121]]` |
| род | `concept__Concept_genus` = ассет, на котором нажали (PropertyDefault `[[f1ef295a-be32-4b52-994e-0d89aa0ae78c]]`) |
| определение | ключ схемы назван каноничным именем свойства — `concept__Concept_definition` |

⛔ **Прежнее описание этой кнопки было устаревшим дважды** и правится вместе с
механизмом: оно обещало папку `concepts/` (литеральный каталог верхнего уровня —
дефект #4357: он лежит вне всех ассетспейсов, и ExoSync его никогда не вывозил) и
предикат `concept__Concept_broader` (ретайрится, тикет `[[9a1e9808-782b-4cfb-a134-833ca102f296]]`;
фактически основание пишет `concept__Concept_genus`).

Историческая справка: кнопка восстанавливала baseline v15.38.0, потерянный при
переезде на RDF. Замещённое основание — `[[e6500fe3-241a-4ba9-aaa0-1ab8a8e0b866]]`
(`service_call`, деприкировано).
