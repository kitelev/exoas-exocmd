# Rollback Done to Backlog

Backward transition from Done → Backlog (Task workflow) as a two-step composite: `Done → Doing` (Re-open) then `Doing → Backlog` (Rollback to Backlog). Clears `ems__Effort_endTimestamp`, `ems__Effort_resolutionTimestamp`, and `ems__Effort_startTimestamp` via the shared rollback dispatcher (`7eb97e7d`), which resolves each step by current status at runtime.

- **Precondition**: `ca0d7bde` — visible only when status = Done and not archived (reuses Re-open gate)
- **Grounding**: composite `9534b950` — steps `[workflow_transition rollback ×2]` (step 1: Done→Doing, step 2: Doing→Backlog)
- **Icon**: undo-2 (Lucide)
- **Category**: status
- **Target class**: `ems__Task`
- **Why**: No direct `Task: Done → Backlog` workflow transition exists; Re-open + Rollback-to-Backlog was used manually (2026-10-02) to undo post-factum Done marks on active Q3-26 review-cycle tasks. Created as one-command composition.
