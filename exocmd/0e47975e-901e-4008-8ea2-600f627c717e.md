# Set status to Waiting

Grounding action that sets `ems__Effort_status` to `[[0610947c-6a62-41c8-9d44-7863d3ba3a8e]]`
(`ems__EffortStatusWaiting` — «задача ждёт внешнего события или ответа»).

Mirrors "Set status to Backlog" (`cfd2d68a`): plain `property_set`, no workflow ABox involved.

## Почему property_set, а НЕ workflow_transition

`GroundingExecutor.executeWorkflowTransition` резолвит переход по паре
`(currentStatus, isRollback)` — то есть из каждого состояния доступен ровно ОДИН forward
и ровно ОДИН rollback. У `Backlog` обе позиции уже заняты (`▶ Start` → Doing,
`← Draft` → Draft), поэтому «припарковать из Backlog» через workflow_transition
выразить нельзя без переопределения существующего перехода.

`property_set` даёт независимую боковую ветку, ничего не отнимая у машины состояний.
